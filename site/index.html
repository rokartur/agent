What else is in the binary

Every account you have
Claude, ChatGPT and GitHub Copilot logins, Anthropic and OpenRouter keys. When one hits its limit, it moves to the next. /usage shows what is left.
Local and open models
Run offline on Ollama or LM Studio, or bring a key for one of 38 hosted providers, from DeepSeek and Groq to Kimi and Z.AI. Any OpenAI- or Anthropic-compatible server works with one line of settings.
Edits by line anchor
If the file changed since it last read it, the edit is refused. No silent overwrites.
Checks its own work
Language server errors and your edit hooks after every change. It fixes what they find.
Rewind
Esc twice goes back to an earlier prompt, and your files go back with it.
Subagents
Big work splits into parallel child agents, tuned in a plain Markdown prompt.
Plugins, MCP, skills
Plugins in any language over JSON-RPC. MCP servers with OAuth. Skills, with /skill-usage to find the dead ones.
Scripts and CI
agent -p prints and exits, --headless streams JSONL, agent acp talks to Zed.
